  • Logo "W" 圆形图标 (F97316)
  • 标题 "晨读计划" (28sp Bold)

  • 密码输入框
  • 提示 "每次启动需重新登录"
  • 登录按钮 (F97316 橙色, 22px 圆角)

📝 RegisterPage

pages/RegisterPage.ets
POST /api/auth/register
  • 顶部返回按钮 "< 返回"
  • Logo "W" + 标题 "创建账号"
  • 账号输入框
  • 昵称输入框 (可选)
  • 密码输入框 (至少6位, InputType.Password)
  • 确认密码输入框 (校验一致性)
  • "注册并登录" 按钮
  • 底部 "已有账号？返回登录"

🏠 MainPage · 背词 Tab

pages/MainPage.ets (StudyHomeTab 内嵌)
GET /api/user/profile GET /api/stats/overview GET /api/books/progress
  • 顶部三栏统计: 累计词数 | 连续天 | 正确率
  • 今日进度: 已完成 X/目标 词
  • 进度条环形 / 线性条 (F97316)
  • 词书下拉: 当前词书名 + 切换
  • 学习模式: "新学" / "复习" 双按钮
  • 核心按钮: "开始背词" → 进入 StudyPracticePage
  • 底部 3 Tab 导航: 背词 | 词书 | 我的

🎯 StudyPracticePage (练习页)

内嵌于 MainPage.ets
GET /api/words/next POST /api/study/submit POST /api/notebook-words
  • 全屏沉浸模式 (替换 MainPage Tab 层)
  • 顶部: 进度指示器 (第 X/总数 题)
  • 单词卡片: 单词(22sp Bold) + 音标 + 释义
  • 点击可查看: 记忆技巧 + 例句 + 译文
  • 4 个选项按钮 (圆角18px, 点击高亮)
  • 选错: 红色 "再记" 标签 + 正确答案标绿
  • 底部三按钮: "加入生词本" | "退出练习" | "提交下一题"

📚 BookTab · 词书页面

内嵌于 MainPage.ets
GET /api/books/progress
  • Swiper 轮播组件 (3 页励志语, 3.2s 自动)
  • 轮播指示器 (dot 样式, F97316 选中色)
  • 每页: 背景图 + 半透明遮罩 + 白色标题
  • 词书卡片列表 (循环渲染 bookList)
  • 每张卡片: 标题 + 等级标签 + 描述
  • 三栏数据: 总词数 | 已学 | 待复习
  • 线性进度条 (accentColor 配色)
  • "当前词书" / "设为当前" 切换按钮

👤 MineTab · 我的

内嵌于 MainPage.ets
GET /api/notebook-words GET /api/wrong-words GET /api/study-records
  • 头像区: 82×82 橙色圆形 + 昵称(22sp Bold)
  • 菜单入口列表 (FFFDF9 底, 圆角24px)
  • • 我的生词本 → N个词 → CollectionPage
  • • 错题本 → N条待复盘 → WrongBookPage
  • • 学习记录 → N天记录 → StudyRecordPage
  • • 个人资料 → 当前词书 → ProfilePage
  • 逐个条目右箭头 ">" 橙色
  • 底部 "退出登录" 按钮 (浅橙底)

📖 CollectionPage · 生词本

pages/CollectionPage.ets
GET /api/notebook-words DELETE /api/notebook-words/{id}
  • 顶部返回栏 "< 返回 我的生词本"
  • Loading 状态 (转圈 + 文字)
  • 空状态: "暂无生词" + 引导文字
  • 单词卡片: 单词(22sp) + 释义(14sp)
  • 右上角: 掌握度标签 (FFF1E6 底)
  • 删除按钮 (红色 FEE2E2 底, 弹窗确认)
  • 底部元信息行: 词书名 | 加入日期 | 下次复习
  • 用户笔记 (notetext, 13sp)

❌ WrongBookPage · 错题本

pages/WrongBookPage.ets
GET /api/wrong-words DELETE /api/wrong-words/{id}
  • 顶部返回栏 "< 返回 错题本"
  • 错误卡片: 单词 + 释义
  • 红色标签 "错误 N 次" (FEE2E2 底)
  • 删除按钮 (弹窗确认)
  • 来源词书 + 最近错误时间
  • 答错句子原文 (14sp, #4B5563)
  • 错误原因: "错误原因：xxx" (13sp)

📊 StudyRecordPage · 学习记录

pages/StudyRecordPage.ets
GET /api/study-records GET /api/stats/overview
  • 顶部返回栏 + 三栏统计摘要卡
  • 连续学习 X天 | 累计完成 X词 | 平均正确率 X%
  • 🎯 月日历打卡视图 (核心亮点)
  • 月标题: "2026年5月"
  • 星期头: 一 二 三 四 五 六 日
  • 7×N Grid 日期格, 学习日橙色圆底
  • 今日蓝色边框高亮, 非当月灰色
  • 底部提示 "橙色圆点表示当天有学习记录"
  • 学习流水列表 (日期+词书+新学/复习/正确率)

⚙️ ProfilePage · 个人资料

pages/ProfilePage.ets
GET /api/user/profile PUT /api/user/profile GET /api/books
  • 返回栏 "< 返回 个人资料"
  • 头像 + 昵称 + "默认词书：XXX"
  • 错误消息区 (E45B5B 红色, 有错误时显示)
  • 昵称输入框 (校验非空)
  • 每日学习目标输入框 (校验>0)
  • 学习签名输入框
  • "保存并返回" 按钮 → PUT /api/user/profile
